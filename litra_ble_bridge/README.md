# Litra Bluetooth Bridge (Home Assistant add-on)

Control Logitech Litra lights (Beam, Beam LX + back RGB, Glow) over Bluetooth
from Home Assistant. Multiple lights supported. MQTT broker credentials are
provided by the Supervisor automatically, and Protection mode stays on.

See [DOCS.md](DOCS.md) for full setup and configuration.

studio-prisma fork of [litra-ble-mqtt](https://github.com/Alevale/litra-ble-mqtt).
